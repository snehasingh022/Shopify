# 🛍️ Responsive E-commerce Product Detail Page

This is a fully responsive and feature-rich e-commerce **Product Detail Page** built with vanilla HTML, CSS, and JavaScript. Inspired by modern Shopify product pages, this implementation includes scrollable galleries, product variants, modals, carousels, tabs, and more—making it perfect for any modern e-commerce platform.

---

## 🔥 Features

- ✅ **Responsive Layout** – Mobile, tablet, and desktop optimized
- 🖼️ **Image Thumbnail Gallery** – Scrollable, zoomable main image
- 🎨 **Color & Size Selectors** – Interactive swatches with availability handling
- 📏 **Size Chart Modal** – Opens detailed size information in a popup
- 🎨 **Compare Colors Modal** – View all color options in a dedicated popup
- 🔄 **Product Bundles** – View and choose complementary product bundles
- 🔄 **Complementary Product Carousel** – Horizontal scrollable suggestions
- 📚 **Tabbed Product Info** – Description, Reviews, FAQs, etc.
- 🔗 **Related Products Grid** – Explore more related items
- 🌟 **Hover Effects & Microinteractions** – Improves user experience
- 💾 **LocalStorage Support (Optional)** – Stores selected variants (toggleable)

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Flexbox, Grid, Animations
- **JavaScript (Vanilla)** – Dynamic UI, Modals, Event Handling
